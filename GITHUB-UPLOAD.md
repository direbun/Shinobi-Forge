# Upload this folder

This directory is the complete Shinobi Forge repository. Nothing outside it is required.

For an empty GitHub repository, open this folder and drag all of its contents into GitHub's **Add file -> Upload files** page. This places the canonical `index.html`, `app.js`, and `styles.css`, together with `Dockerfile`, `package.json`, `server/`, and the remaining project directories, at the repository root.

Do not combine these files with an older copy of Shinobi Forge. In particular, the repository must contain only one root `index.html`, `app.js`, and `styles.css` set.

`dist/` is generated by `npm run build`, but it is included here because this folder is the complete project snapshot rather than a trimmed deployment package.

The folder also includes the source workbook, extraction utility, root character model, static rules copy, tests, documentation, mirrored frontend source, server code, and production build output. Upload the folder contents together; do not select only some of them.

The root page can be used through GitHub Pages for bug checking. It first tries the secure server API and automatically falls back to the repository's rules and shared engine when that API does not exist.

Do not upload `node_modules/` or a real `.env` file. Neither is included here. `.env.example` is safe to commit and documents the required production settings.

This is a client-server application, not a GitHub Pages site. GitHub stores the source; deploy it on the mini PC using the included Docker Compose configuration and the instructions in `README.md`.
